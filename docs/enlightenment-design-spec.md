## 1. 核心理念

### 1.1 启蒙期是"长"出来的，不是"教"出来的

婴儿不知道情绪标签，没有人教它"现在你该高兴"。它通过 **感知 → 内部反应 → 行为 → 反馈 → 状态变化** 的循环，自发形成"世界是什么样、我该如何反应"的模型。

**结论**：现有课程训练（人工构造 `target_mod`/`target_tool`，监督 readout 拟合）违反此原则，等于"替婴儿把世界观写好，再让它背出来"。

### 1.2 硬编码是生物正确的

反射链（饥饿→觅食→哭喊）在人类体内**硬编码在基因里**。项目中的硬编码同理允许：

- 基因预设 = 生存保底 = 后续所有学习的先决条件
- 婴儿出生就会吮吸，不需要学；饿了必须会哭，不能等学习

### 1.3 学习空间在高级情绪

| 层 | 是否硬编码 | 生物学理由 |
|----|-----------|-----------|
| L0 反射 / L1 基本情绪 | **硬编码**（基因预设） | 哺乳动物共享，出生即有 |
| L2 高级情绪 | **学习**（经验塑造） | 依赖自我模型、社会认知，18-24 月后才出现 |

### 1.4 感受保真，过程抽象（2026-08-01 修订）

简化的是**生理实现**（喂食/吸吮/agent 模拟），保留的是**状态表征**（内稳态向量）：

| 保留（感受） | 去掉（过程） |
|-------------|-------------|
| hunger/temp/comfort/fatigue 自发累积 + 时序演化 + 相互耦合 | 妈妈 agent 状态机 |
| 状态 → 情绪耦合（饿 → 烦躁 → 求助） | 喂食/吸吮/消化生理模拟 |
| 行为 → 状态改善 → 奖励 | 按按钮式纯奖励 |

**原则**：奖励标量（scalar）不够，必须保留状态向量（state vector）。

- 纯奖励：SNN 学到"行为 X 有奖励"，但不知道"为什么有奖励"（不知道是饥饿缓解了）→ 状态表征消失 → 同理心失去内感受基础
- 状态向量：SNN 能表征"某个内感受状态 + 它的情绪后果 + 如何缓解" → 看到他人同样状态时激活同一表征 → 同理心的计算底座

**差异化优势**：LLM 无身体（无内感受状态，同理心是纯符号推理）；SNN 有身体（抽象内稳态），同理心有内感受基础——这是"SNN 做 LLM 做不到的事"的具体例证。

## 2. 情绪分层架构

### 2.1 分层总览

```
┌─────────────────────────────────────────────┐
│ 维度 2: 情感纽带（持久感情，跨轮次维持）       │
│   爱 / 信任 / 依恋                           │
│   表征: 纽带强度 × 对象绑定 × 互动历史        │
├─────────────────────────────────────────────┤
│ 维度 1: 情绪状态（瞬时，当前帧）              │
│   L0 反射/内驱（硬编码）                      │
│   L1 基本情绪（硬编码 PAD 公式）              │
│   L2a 自我意识情绪（学习）                    │
│   L2b 自我评价情绪（学习）                    │
└─────────────────────────────────────────────┘
```

### 2.2 区分判据：三个"是否需要"

**判据 A：是否需要"自我"作为情绪对象**（最本质）

- 低级情绪：对象是外部刺激或身体状态，不需要"我"的概念
  - 恐惧 = "有危险"（对象：外部威胁）
  - 饥饿不适 = "身体缺能量"（对象：内感态）
- 高级情绪：对象是"我"或"我与世界的关系"
  - 羞耻 = "我是坏的 / 我丢脸了"（对象：自我）
  - 内疚 = "我做了错事伤害了别人"（对象：我的行为）
  - 自豪 = "我达成了值得骄傲的事"（对象：我的成就）

**判据 B：是否需要他人视角（心智理论）**

- 低级：不需要（恐惧不需要理解他人怎么想）
- 高级：需要（害羞 = 我知道别人在看我并评价我；内疚 = 我理解我伤害了他人）
- 解释了高级情绪在 18-24 个月才出现（心智理论形成窗口）

**判据 C：是否需要归因（因果解释）**

- 低级：刺激→反应，自动
- 高级：归因方向决定具体情绪：
  - 失败归因于"我能力不行"（内部、稳定）→ 羞耻
  - 失败归因于"我不够努力"（内部、可变）→ 内疚（可改变）
  - 成功归因于"我能力强"（内部）→ 自豪
  - 成功归因于"运气好"（外部）→ 侥幸（非自我情绪）

**辅助判据 D-F**：时间尺度（低级短暂、高级持久）、神经基础（低级皮层下、高级前额叶+TPJ+DMN）、跨文化（低级普适、高级文化依赖）。

### 2.3 情绪分类表

| 层级 | 例子 | 需要自我模型 | 需要他人视角 | 需要归因 | 神经基础 |
|------|------|:---:|:---:|:---:|------|
| **L0 反射/内驱** | 饥饿、疼痛、冷热、渴 | 否 | 否 | 否 | 脑干/下丘脑 |
| **L1 基本情绪** | 高兴/悲伤/恐惧/愤怒/惊讶/厌恶 + 好奇(SEEKING) | 否 | 否 | 否 | 杏仁核/边缘系统 |
| **L2a 自我意识情绪** | 尴尬、嫉妒、同理心(认知部分) | 是（基础自我认知） | 部分 | 部分 | 前额叶 |
| **L2b 自我评价情绪** | 羞耻、内疚、自豪、谦虚 | 是（自我评价） | 是 | 是 | 前额叶+TPJ+默认网络 |
| **情感纽带**（非情绪） | 爱、信任、依恋 | 混合 | 混合 | 混合 | CARE 系统 + 前额叶 |

## 3. 硬编码 vs 学习边界

### 3.1 硬编码清单（基因预设）

**L0 反射/内驱（内感态 → 行为）**

| 反射 | 触发条件 | 行为 | 状态 |
|------|---------|------|------|
| 饥饿求助 | hunger > 0.6 | 求助信号（cry 强度↑） | ✅ 已有（`get_teacher_signal`） |
| 寒冷求助 | temperature 偏离 | 趋近温暖源（approach） | ⬜ 需补 |
| 疼痛回避 | 伤害事件 | 回避（avoid） | ⬜ 需补 |
| 疲劳休整 | fatigue > 0.7 | 活动降低 | ✅ 已有（行为语义重定义） |

> **注**：吸吮（suck）已从动作空间移除（纯生理反射，无认知学习价值）。进食功能并入沙盒自动逻辑——饥饿时 cry（求助）+ approach（趋近奖励源）即触发状态改善，不再模拟喂食过程。详见 §6.1。

**L1 基本情绪（调质 → PAD → 情绪，硬编码公式）**

| 情绪 | 调质模式 | 状态 |
|------|---------|------|
| 高兴 | DA↑, 5HT↑ | ✅ PAD 计算已有 |
| 悲伤 | DA↓, 5HT↓ | ✅ |
| 恐惧 | NE↑, 5HT↑ | ✅ |
| 愤怒 | DA↓, NE↑ | ✅ |
| 惊讶 | ACh↑, NE↑ | ✅ |
| 厌恶 | 5HT 特殊模式 | ✅ |
| 好奇/探索（SEEKING） | ACh↑ + DA↑ | ⬜ 需补（事件 `novelty` 已存在，缺 readout 映射） |

**同理心底座（L1，情绪传染）**

| 机制 | 触发 | 响应 | 状态 |
|------|------|------|------|
| 情绪传染 | 同伴哭声/痛苦信号 | 自身 distress↑ + Oxy↑ + 接近倾向 | ⬜ 需补（感知层无"同伴"通道） |

**情感纽带底座（L0/L1，硬编码倾向，强度学习）**

| 机制 | 触发 | 状态 |
|------|------|------|
| 依恋倾向 | 与反复出现的亲近对象互动 | ⬜ 需补（Oxy 通道已有，缺对象绑定机制） |
| 亲社会好感 | 同类在场 | ⬜ 需补 |

**汇总**：已有硬编码 8 条（2 反射 + 6 种基本情绪 PAD）；需补硬编码 6 条（寒冷求助、疼痛回避、SEEKING、情绪传染、依恋倾向、亲社会好感）。

### 3.2 学习空间（L2，经验塑造）

| 层 | 情绪 | 载体 | 信号来源 |
|----|------|------|---------|
| L2a | 尴尬、嫉妒、认知同理心 | 沙盒 v2（同伴互动） | 社会反馈 + 内稳态 |
| L2b | 羞耻、内疚、自豪、谦虚 | 沙盒 v3（评价者） | 评价反馈 + 归因 |

### 3.3 可操作落点

> **高级情绪 = 去掉"情境 + 自我 + 记忆"输入通道后无法产生的情绪。**

- L0/L1 readout 输入：当前帧感知 + 当前调质（单时间点、无自我）
- L2 readout 输入：当前状态 + 情境表征（谁在场/什么事件）+ 自我模型 + 记忆检索

## 4. 同理心双层结构

同理心不是单层情绪，是**"硬编码底座 + 学习放大"的双层结构**：

| 成分 | 机制 | 生物学基础 | 层 | 编码方式 |
|------|------|-----------|-----|---------|
| 情绪传染 | 看到同伴哭→自己也难受（新生儿即有） | 镜像神经元 + 催产素 | L1 | 硬编码 |
| 亲社会好感 | 对同类天然偏好、靠近倾向 | CARE 系统 + Oxy | L1 | 硬编码 |
| 认知同理心 | 换位思考→理解他人处境→主动帮助 | 心智理论 + 前额叶 | L2a | 学习 |

**原则**：同样的能力，底层硬编码、高层学习。项目 Oxy 通道（`oxy_conc`）即硬编码底座。

**内感受基础（2026-08-01 修订）**：同理心的底座还包括**共享的内感受状态表征**——SNN 保留 hunger/temp 等状态向量（§1.4），看到他人处于同样内感受状态时激活同一表征，这是"感同身受"的计算基础。若简化为纯奖励标量（无状态向量），此基础消失，同理心退化为纯符号推理（即 LLM 的局限）。**保留状态向量 = SNN 同理心的差异化优势**。

## 5. 情感纽带（爱/信任/依恋）

### 5.1 定位

**爱不是瞬时情绪，是持久的"感情"（情感纽带）**——跨轮次维持的长期状态，不进情绪层，单独建模。

### 5.2 成分拆解

| 成分 | 生物学机制 | 层 | 编码方式 |
|------|-----------|-----|---------|
| 生理依恋 | CARE 系统 + Oxy（亲子/伴侣） | L0/L1 | 硬编码（哺乳动物共享） |
| 激情渴望 | LUST/SEEKING + DA | L0/L1 | 硬编码 |
| 亲密感 | 互动历史积累 → 记忆中的亲密度 | L2 + 记忆 | 学习 |
| 信任/承诺 | 长期预测"对方可靠" → 行为稳定倾向 | L2 + 记忆 | 学习 |
| 持久性 | 不随刺激消失，跨天-年 | 时间尺度维度 | 混合 |

### 5.3 代码落点

- 表征：`bond_strength × bond_target × interaction_history`
- 硬编码底座：项目已有 Oxy 通道 + CARE 对应的催产素受体
- 学习成分：互动历史写入海马（`HippoIndex` 加 `bond_target` 字段）→ 亲密度累计 → 对特定 agent 的反应调制

## 6. 世界沙盒架构

### 6.1 动机

**无法构建完整的虚拟社会给 AI** → 将除网络本身以外的所有环节抽象为一个**沙盒（Sandbox）**。

- 网络只做：感知 → 内部状态 → 情绪/决策 → 行为
- 网络不关心：世界如何运转、谁在评价、食物哪来的
- 沙盒内部可任意实现、可替换、可分级演进

```
┌─────────────────────────────────────────────┐
│ SNN 网络（唯一真实实现，认知核心）            │
│   只做：感知→内部状态→情绪/决策→行为          │
└────────────────────┬────────────────────────┘
                     │ 稳定接口（永不改变）
┌────────────────────┴────────────────────────┐
│ 世界沙盒（可替换、可分级、内部任意实现）        │
│   ├─ 内稳态：状态向量演化（hunger/temp/       │
│   │          comfort/fatigue，自发+时序+耦合）│
│   ├─ 行为映射：行为→状态改善→奖励（无 agent） │
│   ├─ 事件发生器：威胁/社交/成就/新奇           │
│   ├─ 社会反馈：表扬/批评/评价（L2b 载体）      │
│   └─ 任务环境：工具执行结果（Phase 3d 载体）   │
└─────────────────────────────────────────────┘
```

> **2026-08-01 修订（沙盒 v1 极简化）**：v1 沙盒**不包含 agent 行为模型**。
> 内稳态状态向量（感受）保留；妈妈 agent 状态机、喂食/吸吮生理过程（解决感受的过程）移除，
> 替换为"行为 → 状态改善 → 奖励"的直接映射：
> `cry → P(求助有效)=f(hunger,强度) → hunger↓ + DA`。
> 复杂 agent（同伴/评价者）推迟到 v2/v3——那时才有真正的认知目标（同理心/自我评价）。

### 6.2 最小接口契约（稳定不变）

| 接口 | 方向 | 内容 | 现有对应 |
|------|------|------|---------|
| `observe()` | 沙盒→网络 | 感知向量（触觉/听觉/视觉/嗅觉/内感态 + 情境标签） | `compute_sensory_signals` ✅ |
| `act()` | 网络→沙盒 | 动作向量（cry/gaze/approach-avoid/interact/limb + 未来工具调用） | `step_env(motor)` ✅ |
| `feedback()` | 沙盒→网络 | 奖励标量（内稳态改善/社会反馈/任务结果） | `compute_reward` ✅ |
| `inject_event()` | 沙盒→网络 | 离散事件→调质增量（沿用 GENE_MAP） | `event_scheduler` ✅ |
| `state()` | 沙盒→网络 | 内感态查询（L0 反射硬编码用） | `get_body_state` ✅ |

**关键原则**：网络只依赖这 5 个接口。沙盒内部升级（v1→v4），网络代码一行不改。

**动作空间设计（2026-08-01 修订）**：动作空间 = 认知行为的最小完备集，每个动作对应一个可学习的认知维度；纯生理细节全部下沉到沙盒。

| 动作 | 认知意义 | 承载的学习 |
|------|---------|-----------|
| cry（求助） | 求助信号 | 何时求助有效（L0 硬编码 + 微弱学习） |
| gaze（注视） | **注意选择** | 学会"看什么"（认知核心能力） |
| approach / avoid（趋近/回避） | **价值判断** | 什么值得趋近、什么该回避（SEEKING/FEAR 行为输出） |
| interact（互动） | 对象交互 | v2 起：同理心、依恋、游戏 |
| limb（运动） | 探索 | 环境探索 |

> 吸吮（suck）已移除——纯生理反射（脑干层面基因写死），无认知学习价值，仅占动作槽位。
> 进食功能并入沙盒自动逻辑（饥饿时 cry + approach 即触发状态改善）。

### 6.3 沙盒分级演进

| 版本 | 沙盒内容 | 承载能力 | 对应阶段 |
|------|---------|---------|---------|
| **v1**（重构后） | 内稳态状态向量 + 行为→奖励映射（无 agent 模拟） | L0 反射 + L1 基本情绪 + 内稳态学习 | 启蒙早期 |
| **v2** | + 同伴 agent（哭声/互动） | 同理心底座 + 依恋形成（L2a） | 启蒙后期 |
| **v3** | + 评价者（表扬/批评/竞争） | L2b 自我评价情绪（羞耻/自豪/内疚） | 课程期 |
| **v4** | + 任务工具环境 | Phase 3d 工具调用 + 具身 RL | 课程期+ |

## 7. 训练范式调整

### 7.1 N3F 第三因子来源变更

| 维度 | 旧（课程监督） | 新（沙盒反馈） |
|------|--------------|--------------|
| 第三因子来源 | readout 误差反传（人工 target） | 沙盒 `feedback()` 奖励 |
| 信号类型 | 监督信号（MSE + CE） | 内稳态改善 / 社会反馈 / 任务结果 |
| 生物学对应 | 无（反传误差非生物机制） | 多巴胺奖赏预测误差 |
| 注入时机 | 每步注入 | 沙盒反馈事件触发 |
| 虚假误差风险 | 高（事件时序失配） | 低（反馈来自真实世界状态变化） |

### 7.2 课程训练降级

- 课程数据（人工构造 `target_mod`/`target_tool`）**仅用于 readout 冷启动**（模仿学习，校准决策层）
- **不再注入** `neuron_eligibility` 到突触（消除虚假误差源，对应 N3F 缺陷 §7.1/§7.7）
- 突触塑形回归生物信号：STDP（无监督）+ 沙盒反馈（三因子）

### 7.3 情绪 readout 分层训练

| readout | 训练方式 |
|---------|---------|
| L0/L1（调质→PAD→基本情绪） | **硬编码公式**（不训练） |
| L2（情境+自我+记忆→高级情绪） | **沙盒自组织学习**（v2/v3 反馈） |
| 情感纽带（Oxy→对象绑定） | 硬编码倾向 + 互动历史学习 |

| 层 | 载体 | 塑形信号 | 状态 |
|----|------|---------|------|
