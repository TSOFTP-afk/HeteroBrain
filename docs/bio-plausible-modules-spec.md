# 生物拟真模块扩展 Spec（设计记录，2026-08-06）

> 状态：**设计记录，未实施**。本 spec 记录"按生物拟真路线，60K 神经元规模上应补充的情感相关微环路"。
> 讨论背景：当前 SNN 已有 31 种生物机制（AdEx/NMDA/STDP/STP/CaMKII/丘脑门控/睡眠重放/WM/海马/6 通道调质）。
> 结论：60K ≈ 果蝇脑量级，应加**微环路/机制**而非整个脑区；优先补**情感学习回路**与**时间尺度层级**。

## Why

情感核心定位下，当前网络的三个生物拟真缺口：

1. **无情感学习**：事件→情感是外部浓度模拟器开环，网络永远学不会"刺激→情绪反应"（CS-US 条件反射缺失）；
2. **奖赏学习是数值不是动力学**：TD error 在 host 端计算，DA 只是浓度变量，没有"发放=学习信号"的神经实现；
3. **时间尺度缺失**：情绪只有快通道（NE/GABA 秒级），缺分钟级持久应激（HPA 轴）与恢复动力学。

## 模块方案（按优先级）

### M1 杏仁核样情感学习核心（最优先）
- **生物学**：杏仁核 LA→BA 回路 = 情感条件反射中枢；丘脑→杏仁核快速通路不经皮层精加工。
- **功能**：事件表征 + 皮层活动 → STDP 学刺激-情感反应关联 → 输出调质系统；支持消退（extinction）与泛化。
- **接入**：~2K 神经元小模块（接在联合皮层旁），输入 = 事件表征 + 皮层活动，输出 = 调质系统；新 STDP 通路 kernel，无新持久数据结构。
- **与工程 P0 的关系**：事件注入只解决"事件进网络"，杏仁核解决"网络学会情感反应"——是 P0 的升级版。

### M2 VTA-DA 真实奖赏环路
- **生物学**：VTA DA 神经元发放 = 奖赏预测误差（RPE）：奖赏 burst / 预期落空 dip。
- **功能**：DA 群体发放率 = RPE，作为 STDP 第三因子（替换从浓度数组读 DA），readout 改读 DA 群体发放。
- **接入**：~1K 神经元群体；皮层→VTA + VTA 投影。

### M3 HPA 应激慢轴（皮质醇）
- **生物学**：NE 快应激（秒级）+ HPA→皮质醇慢应激（分钟级持久、事件后恢复惯性）。
- **功能**：第 7 个调质通道（或 Oxy 旁路）：事件后缓慢升、更缓慢降，调制 5HT/GABA 基线（慢性应激→5HT 降）。
- **接入**：无神经元，纯浓度数组（60K×4B）+ host 模拟器——**几乎零开销**。

### M4 脑岛内感受→情感映射
- **生物学**：脑岛整合内感受（心跳/饥饿/疼痛/温度）→ 主观情绪（"先有身体反应，才有情绪"）。
- **功能**：body 状态（hunger/pain/temp）→ 脑岛群体 → 情感 readout，情感获得身体锚点。
- **接入**：~1K 神经元；复用现有 `encode_interoception`（15 柱）作输入。

### M5 基底节 Go/NoGo 决策环（远期）
- **生物学**：皮层→纹状体→丘脑→皮层决策环，Go/NoGo 门控。
- **功能**：意图决策的神经实现，对应工具 readout 恢复训练（w_tool）时接入。
- **接入**：~2K 神经元。

## 开销估算（精确基数：BioSynapse=80B，现有 10.7M 突触/60K 神经元/1543MB）

| 模块 | 神经元 | 突触（入度~200） | 显存 |
|---|---|---|---|
| M1 杏仁核 | 2K | 400K | ~34 MB |
| M2 VTA-DA | 1K | 200K | ~17 MB |
| M3 HPA 皮质醇 | 0 | 0 | <1 MB |
| M4 脑岛 | 1K | 200K | ~17 MB |
| M5 基底节 | 2K | 400K | ~34 MB |
| **合计** | **~6K（+10%）** | **~1.2M（+11%）** | **~110 MB（+7%，上限 150 MB）** |

- 显存大头是突触（80B/条），神经元状态 <1MB——**控制入度比神经元数更关键**（入度 200→100 开销减半；边缘系统稀疏连接在生物学上也合理）。
- RTX 3060（6GB）：当前进程 2.52GB、余量 3.47GB，新增 110-150MB 无压力。
- 步耗时与突触数近似线性：+11% ≈ 140ms→154ms/步（80K 步 +~19min）。

## 实施顺序建议

1. **M3 HPA 皮质醇**（几乎免费，顺手先加，补慢时间尺度）；
2. **M1 杏仁核情感学习核心**（核心价值：情感学习进网络，直击 readout 根因）；
3. **M2 VTA-DA**（奖赏学习神经动力学化，与 M1 联动）；
4. **M4 脑岛**（情感身体锚点）；
5. **M5 基底节**（意图决策，随工具通道恢复）。

- **设计**：5 维内感受（hunger/temp_dev/comfort/fatigue/pain）× 200 神经元简单 LIF，无学习权重（身体锚点非学习器官）；15 柱 one-hot → 5 维强度（scheduler.set_insula_sensory 换算）；调制更新时读窗口累计发放率 → 不适→NE↑、舒适→Oxy↑

- **踩坑 1（读取相位）**：注入电流 0.4 + 阈值 0.5 → 2 步才发放；读取点固定在偶数步（100/200/300）恰在"注入后未达阈值"相位 → 永远读 0。修复：`d_insula_accum[5]` 窗口累计发放计数（kernel 内 atomicAdd），读取归一化 `cnt/(window_steps×group_size)` 并清零。
- **踩坑 2（清零时序）**：`launch_modulatory`（L670）先于日志块（L707）执行，其内部偏置 read 若清零 → 日志 read 读到 0。修复：偏置 read 不清零，日志 read 清零（注释已说明）。

### M2 VTA-DA 设计（2026-08-06，已交付）

**目标**：DA 群体发放率 = RPE（奖赏预测误差），作为 STDP 第三因子 DA 项的神经化来源——"奖赏学习神经动力学化"，与 M1 杏仁核联动（杏仁核输出 DA 偏置→浓度，VTA 输出 RPE→STDP）。

**模块**（独立小模块，与 M1/M4 同风格）：
- 1000 神经元简单 LIF，2 组：正 RPE 500（奖赏 burst）/ 负 RPE 500（预期落空 dip），无学习权重
- 输入（RPE 信号源）：复用 launch_modulatory 现有信号——`da_delta > 0`（正 DA 变化=奖赏）注入正组；`prediction_error_norm`（预测误差）注入负组。host 端每调制窗口缓存一次（h_vta_rpe_[2]），scheduler.step() 每步注入（与脑岛同模式）
- 输出：`r_vta = (正组发放率 - 负组发放率)` 归一化 [-1,1]

**侵入点（复杂度高，需确认）**：
- `stdp_dual_trace_kernel` + `stdp_arrival_pre_kernel`：`s.da_receptor * da_conc[post]` 的 DA 项替换/混合为 VTA 发放率。两个 kernel 签名 + 2 个调用点 + 新参数
- 风险：10.7M 突触核心学习动力学变更，可能动摇 80K/90K 已验证判据（事件可辨性 ratio>2 + readout 可纠正性）
- 备选低风险路径：VTA 发放率不替换浓度 DA，而是作为独立叠加项（`+ vta_gain · r_vta · da_receptor`）——浓度 DA 语义不变，VTA 提供额外 RPE 调制

**readout 联动（不建议本轮做）**：spec 原案"readout 改读 DA 群体发放"会牵动训练目标（readout 监督浓度模拟器 6 维目标），与 B 交付的判据重定义冲突，建议 M2 首轮只做 STDP 第三因子接入，readout 保持浓度监督。

**验证**：300 步冷启动冒烟——[VTA] 日志（正/负组发放率 + r_vta）；事件（achievement→正组↑、criticism→负组↑）后 r_vta 方向正确；浓度/readout 行为不回退。

**实施记录**：
- **文件**：`vta_kernels.cuh/.cu`（新建）+ config.h 常量 + memory_allocator 4 缓冲 + CMake + network_init + scheduler 接线 + synapse_kernels（STDP 第三因子）
- **接线**：scheduler.step() 每步 `launch_vta_inject(h_vta_rpe_inject_) + forward`；scheduler::launch_modulatory 内每窗口①更新注入缓存（`da_delta>0`→正组×VTA_POS_GAIN、`prediction_error_norm`→负组×VTA_NEG_GAIN）②读 VTA 窗口累计发放率→`h_vta_rpe_` ③[VTA] 日志；stdp_dual_trace/arrival_pre 的 M_ij 内 DA 项改为 `da_receptor·(da_conc[post] + VTA_STDP_GAIN·vta_rpe)`

- **readout 联动未做**（本轮）：readout 保持浓度监督，避免牵动训练目标（见上"不建议"说明）
