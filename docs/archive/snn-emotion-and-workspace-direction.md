# SNN 方向评估：情感核心 + 认知工作空间

> 本文档记录 2026-07-30 一次方向讨论的完整推演过程，从对原 Phase 3 双系统协作方案的
> 质疑出发，逐步推导出"SNN 情感核心"定位，再到"认知工作空间（Cognitive Blackboard）"
> 架构跃迁。结论：**情感核心 + 认知工作空间** 应作为 Phase 3 的真正方向，取代原方案中
> 的"6 个分类头"定位。

---

## 1. 起点：原 Phase 3 方向评估

### 1.1 原方案回顾

原 [phase3-t2h-distillation-plan.md](./phase3-t2h-distillation-plan.md) 提出的双系统协作架构：

- **LLM（MiniCPM5-1B）+ RAG**：负责知识库 + 语言生成
- **SNN（60K 神经元）**：作为"逻辑处理器"，输出 6 个分类头
  - 意图分类（8 类）、情绪识别（5 类）、相关性回归、质量回归、重生成决策、记忆存档决策
- **三阶段流水线**：SNN 前置判断 → LLM+RAG 生成 → SNN 后置评估（含重生成循环）

### 1.2 核心问题

| 问题 | 说明 |
|---|---|
| **SNN 存在性存疑** | 6 个分类头本质是 6 个共享 backbone 的线性分类器，2 层 MLP 即可替代，60K 神经元 + 10.7M 突触 + CUDA BPTT 严重过度 |
| **内部默读自相矛盾** | 256 类字节 decoder 表达能力不足（生成质量差），却用它评估 LLM 生成质量——评估器比被评估对象弱 |
| **延迟目标不现实** | 三阶段流水线 + 重生成（最多 2 次）最坏 > 4 秒，CMD 交互体验差 |
| **SNN 优势未发挥** | 时序动力学、STDP 在线学习、多时间尺度——这三样 SNN 真正擅长的能力一个都没用上 |
| **文档不一致** | roadmap / README / PROJECT_MEMORY 仍写旧 T2H 蒸馏方案 |

### 1.3 关键诊断

> 新方案里的 SNN 是"为了保留而保留"，不是"因为不可替代而保留"。
> 如果删掉 SNN 换成 6 个 MLP，系统功能和性能几乎不变，反而更简单。

## 2. SNN 真正的"独占领地"

剥离伪优势（低功耗、稀疏、生物可解释——在通用 GPU 上都不成立），SNN 相对 Transformer 的真优势收敛为**三块领地**：

### 领地 1：连续状态维持（时序动力学）

> 维持一个跨轮次、连续演化、有惯性、有衰减的内部状态。

- **机制**：膜电位衰减、不应期、阈值适应、STP
- **Transformer 为何做不到**：每次推理无状态，靠 KV cache 硬撑，cache 是"复读机式"记忆而非"状态演化"
- **应用**：情感核心、用户疲劳度追踪、对话张力曲线、话题热度衰减

### 领地 2：在线局部学习（STDP）

> 几个样本就形成突触模式，不重训、不污染全局。

- **机制**：STDP、PSW 贝叶斯突触、CaMKII 巩固
- **Transformer 为何做不到**：在线学习有灾难性遗忘，in-context learning 又是"用完即弃"
- **应用**：用户个性印记、即时偏好适应、小样本习惯学习

### 领地 3：多时间尺度并行（慢变量分层）

> 同一网络内秒级 / 分钟级 / 小时级动态并存。

- **机制**：不同突触/神经元时间常数、发育阶段分层
- **Transformer 为何做不到**：所有 token 同一时间步，没有"小时级慢变量"概念
- **应用**：短期情绪（秒）+ 中期话题偏好（分钟）+ 长期性格（小时/天）三层并行

### 三块领地的共性

一个 SNN 角色要"立得住"，必须**同时满足**：
1. 用到时序动力学或 STDP（不是每轮独立分类）
2. Transformer 做不到或做得差
3. 现有 SNN 代码能复用
4. 有可验证指标
5. 有可视化卖点

## 3. 方向一：SNN 作为情感核心

### 3.1 为什么这个定位立得住

情感在生物脑中恰恰由 SNN 擅长的脑区承担：**杏仁核、ACC、腹侧纹状体、岛叶**。它们的共同特征：

| 生物特征 | SNN 对应能力 |
|---|---|
| 时序动态（情绪秒-分钟级演化） | membrane potential、spike timing |
| 神经调制（多巴胺/血清素全局影响） | `modulatory_kernels.cu` 已存在 |
| 慢变量（情绪跨轮次持续） | 神经元适应 + STP |
| 全局状态（调制神经元宽投射） | 丘脑门控 + 调制内核 |

**关键洞察**：原方案让 SNN 做"句子级分类"（贴标签）——这是 SNN 最不擅长的（静态、独立、无需时序）。而"维持跨轮次的情感状态"才是 SNN 真正不可替代的角色。

### 3.2 三个具体职责

**职责 1：维持情感状态向量（affective state）**

不是 5 类离散情绪，而是连续空间（推荐 PAD 模型或 8-16 维）。跨轮次演化：

```
轮次1: 用户"今天好累" → state = [P=0.2, A=0.3, D=0.4]
轮次2: 助手共情回复   → state 演化 = [P=0.35, A=0.25, D=0.4]  (缓慢回升)
轮次3: 用户"还是烦"   → state = [P=0.15, A=0.5, D=0.3]        (下沉)
```

SNN 的膜电位衰减、STP 机制天然产生这种"渐变"动态——**MLP 分类头做不到**。

**职责 2：神经调制信号输出**

SNN 输出模拟的神经调质浓度，调制 LLM 生成参数：

| SNN 输出 | 调制对象 | 效果 |
|---|---|---|
| 多巴胺（奖励/兴趣）↑ | LLM temperature ↑ | 更活跃、更有创意 |
| 血清素（稳定/满足）↑ | LLM temperature ↓ | 更稳重、更保守 |
| 去甲肾上腺素（警觉）↑ | top_p ↓ + repetition_penalty ↑ | 更聚焦、不跑题 |
| 情感状态向量 | system prompt 注入 | "当前情绪基调：温和共情" |

这是比"6 分类头影响 prompt 模板"**更有机的集成方式**——SNN 不再只是给 LLM 喂标签，而是**调制 LLM 的生成过程本身**。

**职责 3：情感记忆印记（STDP 驱动）**

用户多次表达相似情绪时，SNN 通过 STDP 形成"情感印记"突触模式：
- 这是 LLM+RAG 做不到的——RAG 是精确语义检索，SNN 是模糊情感模式匹配
- 用户 A 长期焦虑倾诉 → SNN 形成焦虑响应模式 → 见到 A 时自动进入共情状态
- 真正的"个性化"，不靠微调 LLM 权重

### 3.3 6 维调质向量设计

基于人类情感神经调质的研究，工程建议建模 6 维：

```cpp
neuromodulator_state[6] = {
  dopamine,      // 奖励/动机/探索      (DA,  τ=100ms)
  serotonin,     // 稳定/满足           (5-HT, τ=300ms)
  norepinephrine,// 唤醒/警觉           (NE,  τ=150ms)
  acetylcholine, // 注意力/记忆编码     (ACh, τ=200ms)
  gaba,          // 抑制/平静           (新增全局变量)
  oxytocin       // 共情/社交联结       (完全新增)
}
```

**为什么选这 6 个**：覆盖情感主要维度（愉悦/稳定/唤醒/注意/平静/共情），都是"快变"调质，与 SNN 时序动力学匹配，可与 PAD 模型双向映射。

**不要做的事**：
- 不要 12+ 维（参数过多，训练数据无法支撑）
- 不要加激素（太慢，与对话轮次不匹配）
- 不要 1 调质 = 1 标签（丢失组合性，退化回分类）

### 3.4 事件驱动调质注入 (Phase 3a-C / 留待 Phase 3b 实现)

> **核心洞察 (2026-07-30 5K 步测试反馈)**：情绪是事件在人身上的反馈，不是数据流的副产品。当前 `launch_modulatory` 的所有信号都来自 SNN 内部状态 (spike 统计 / TD error / 解码误差)，导致情绪是"网络自己跟自己玩"的产物，没有语义锚点。

#### 问题诊断

5K 步合成输入测试显示 DA=0.736、ACh=0.932、Pleasure=+0.482 —— 表面稳定，但这些数值的成因是 spike 统计恰好落入某个区间，**不是因为"吃到好吃的"或"解出题了"**。这种情绪状态无法解释、无法控制、无法对齐用户意图。

#### 架构改造方向

```
┌─────────────────┐    离散事件     ┌──────────────┐    连续信号    ┌─────────┐
│  事件源 (离散)   │ ─────────────→ │ 事件→调质映射 │ ─────────────→ │   SNN   │
│  - 吃高糖食物    │                │  (基因硬编码) │                │ (连续)  │
│  - 打猎成功      │                │  food→DA↑    │                │         │
│  - 被攻击        │                │  hunt→DA↑+NE↑│                │         │
│  - 被夸奖        │                │  pain→5HT↑+NE↑│               │         │
│  - 社交互动      │                │  praise→Oxy↑ │                │         │
└─────────────────┘                └──────────────┘                └─────────┘
       ↑                                                                  ↑
   波动数据流                                                      连续调质背景
   (文本/感官)                                                    (情绪状态)
```

#### 三类事件来源

1. **先天情绪 (基因硬编码映射表)**：进化刻在基因里的事件→调质映射
   - 高糖/高热量食物 → DA↑ (奖赏)
   - 疼痛/受伤 → 5HT↑ + NE↑ (应激)
   - 低温 → NE↑ (唤醒)
   - 突然巨响 → NE↑ + ACh↑ (惊跳)
   - 这些映射是"出厂设置"，不需要学习

2. **社会情绪 (等价代换)**：复用先天映射表
   - 发工资 ≈ 打猎成功 → DA↑ + NE↑
   - 被夸奖 ≈ 社交接纳 → Oxy↑ + DA↑
   - 被批评 ≈ 社交排斥 → 5HT↑ + DA↓
   - 被攻击 ≈ 身体威胁 → NE↑ + 5HT↑
   - 代换规则在事件评估器中定义

3. **认知情绪 (内部状态驱动)**：保留现有 launch_modulatory 逻辑
   - novelty (SNN 内部惊奇) → ACh↑
   - prediction_error (解码误差) → DA 调整
   - TD error (价值函数) → DA delta
   - 这些是"思考过程"产生的情绪，与外部事件叠加

#### 关键设计原则

- **事件是离散脉冲，SNN 是连续系统**：事件触发调质浓度阶跃，然后按 tau 衰减 —— 这正是现有 `conc[t+1] = conc[t]*decay + signal[t]` 方程的天然用法，无需改动力学
- **数据集应该是波动的，事件是离散的**：训练数据 = 连续感官流 (文本/字节) + 离散事件标注 (时间戳+类型+强度)
- **事件注入是叠加，不是替换**：外部事件信号 + 内部认知信号 共同驱动调质，保持两者并存
- **基因映射表不可训练**：先天映射是硬编码的，防止 SNN 学出"反人性"情绪反应

#### 实现路径 (Phase 3b 时启动)

1. 定义 `EventType` 枚举 (food_tasty / hunt_success / pain / threat / praise / criticism / social_bond / novelty_internal 等 8-12 种)
2. 在 `launch_modulatory` 加 `inject_event(EventType, float intensity)` 接口
3. 定义基因硬编码映射表 `GENE_EVENT_MAP[EventType] -> {DA_delta, ACh_delta, NE_delta, 5HT_delta, GABA_delta, Oxy_delta}`
4. 主循环加事件调度器，从 `events.jsonl` 按时间戳注入
5. 扩展 `generate_synthetic_grab_traces.py` 生成带事件标注的数据集 (复用现有 phase_templates 的 CS/US 结构)
6. 验证准则：同一事件序列下，SNN 情绪响应可解释、可复现、符合生物规律

#### 与 Phase 3b 的关系

这个改造与认知工作空间天然耦合：
- 事件 → 工作空间写入 (记录"发生了什么")
- 工作空间 → 调质评估 (基于记忆评估事件意义)
- 调质 → SNN 状态演化 (情绪背景影响后续思考)
- SNN → 工具调用 (基于情绪状态选择应对策略)

因此建议在 Phase 3b 认知工作空间设计时一并实现，避免重复改动 `launch_modulatory` 接口。

## 4. 现有 SNN 实现的契合度盘点

### 4.1 已实现的神经调质（4/6 就绪）

| # | 调质 | 衰减常数 | 受体密度字段 | 现状 |
|---|---|---|---|---|
| 1 | 多巴胺 DA | 100ms | `da_receptor` (float) | 已实现 + TD 价值函数 |
| 2 | 乙酰胆碱 ACh | 200ms | `ach_receptor` (float) | 已实现 |
| 3 | 去甲肾上腺素 NE | 150ms | `ne_receptor_u8` (定点) | 已实现 |
| 4 | 血清素 5-HT | 300ms | `ht5_receptor_u8` (定点) | 已实现 |
| 5 | GABA | — | GABA_A/B 受体已有 | 缺全局浓度变量 |
| 6 | 催产素 | — | — | 完全需新增 |

**升级到 6 维只需：改 1 个字段 + 加 1 个浓度变量**。基础设施几乎全部就位。

### 4.2 生物机制总数：31 种

### 4.3 与情感核心方向的契合度

| 情感核心需求 | 现有代码就绪度 | 改造量 |
|---|---|---|
| 6 维调质向量 | **67%**（4/6 已实现） | 加 2 个字段 |
| 连续状态维持 | **90%**（DA/ACh/NE/5HT τ 不同，天然多时间尺度） | 加 readout |
| 神经调制信号输出 | **95%**（modulatory_kernels 已是浓度动力学模型） | 加 LLM 接口 |
| 情感记忆印记 | **100%**（PSW + 海马索引 + WM 全部就绪） | 直接复用 |
| 跨时间尺度分层 | **80%**（调质 τ 不同 + 发育阶段分层） | 加情感层映射 |

**关键发现**：原 phase3 方案（6 分类头）只用了 PCA readout 一条线，**抛弃了 31 种生物机制里的 29 种**；而情感核心方向能复用 20+ 种，让这些精心实现的代码真正发挥价值。

## 5. 现有记忆机制诊断

### 5.1 记忆体系总览（4 层 + 1 压缩层）

```
                    [PCA 压缩层]
                  50K 发放率 → 50 维签名
                        ↓
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
   [工作记忆 WM]    [海马索引]      [突触权重]
   50 槽位          50K 槽位       10.7M 突触
   秒级保持          长期存储        永久（PSW）
        ↓               ↓
   注入前额叶       睡眠重放
   (每步)          (每10K步)
```

### 5.2 各层实现细节

**PCA 压缩层**（统一签名层）：把 50K 维发放率压成 50 维签名，所有记忆子系统的"通用货币"。

| 操作 | 公式 | 触发 |
|---|---|---|
| 签名提取 | `sig[k] = Σ_i W[i,k]·(fr[i] - mean[i])`，L2 归一化 | 每 100 步 |
| 增量学习 | `W[i,k] += η·(x[i] - W[i,k]·sig[k])·sig[k]` (Oja's rule) | 每 100 步 |
| 反投影重建 | `recon[i] = mean[i] + Σ_k sig[k]·W[i,k]` | 按需 |

**海马索引**（长期记忆）：50K 槽位 × 256B = 12.8MB。每 100 步取 PCA 签名与 50K 索引做 cosine 匹配，sim ≥ 0.7 判为已有模式（刷新 importance），sim < 0.7 判为新颖模式（LRU 写入）。

**工作记忆**（短期保持）：50 槽位 × 216B，绑定 50 个前额叶组。衰减因子 0.995/步（半衰期约 138 步 / 1.4 秒模拟时间），activation > 0.3 时 PCA 反投影注入前额叶。

**突触权重**（永久记忆）：10.7M 突触 × 80B = 856MB。PSW 贝叶斯 STDP：`w_eff = W_MAX · α/(α+β)`，LTP → α 累积，LTD → β 累积，元可塑性自然涌现。

**睡眠重放**（巩固机制）：每 10K 步取 importance top-200，PCA 反投影重建发放率 ×2.0 注入，重放后 importance ×= 0.9，ACh 切换到睡眠态 ×0.3。

### 5.3 五个关键问题

| 问题 | 说明 |
|---|---|
| **海马与 WM 算法重复** | 两者都是"cosine + LRU + novelty"，唯一区别是容量和时间常数。生物学上不对——海马是情景记忆索引，WM 是前额叶主动维持，机制应不同 |
| **只存签名不存内容** | 记忆里只存 50 维 PCA 签名。要"回忆"内容靠 PCA 反投影重建神经活动，但**不能重建语义内容**。用户说过的"我今天很累"这句话本身不在 SNN 里 |
| **没有时间戳/因果结构** | `HippoIndex` 只有 `pattern_start_step`（训练步戳），无真实时间戳、无上下文关联、无因果标记。无法做"昨天我们聊过 X"这种时序回忆 |
| **没有用户隔离** | 所有记忆共享一张 50K 索引表，无 `user_id` 字段。多用户场景下会串记忆 |
| **没有情感维度** | `HippoIndex` 字段只有签名/步戳/重放次数/importance。无法区分"高兴时聊的话题"和"难过时聊的话题"——而生物学上杏仁核-海马回路恰恰会给记忆打情感印记 |

### 5.4 改造建议（最小侵入）

**必须改（结构改动）**：
1. `HippoIndex` 加 3 个字段：`emotion_tag[6]`、`user_id`、`real_timestamp`
2. WM 槽位加情感绑定

**应该改（算法改动）**：
3. 海马写入时打情感印记：`emotion_tag = current_neuromodulator_state`
4. 海马检索时按情感加权：`score = cosine_sim + α × emotion_match_score`
5. 睡眠重放按情感显著性：`importance_emotional = importance × (1 + |emotion_tag|)`

**可以不动**：PCA 压缩层、PSW 突触权重、WM 衰减机制、睡眠重放框架全部复用。

## 6. 方向二：认知工作空间（Cognitive Blackboard）

### 6.1 核心洞察

> 人脑算数学题时，"纸"和"口算"的差别不是快慢，而是**两种根本不同的认知架构**。
> 纸不是"辅助工具"，纸是**认知架构的一部分**（Clark & Chalmers 1998 扩展心智论题）。
> 算 23×17 时，你不是在脑子里算，你是在"脑子 + 纸 + 笔"这个**分布式系统**里算。

SNN 主流研究的盲点：**所有记忆都被塞进神经元状态或突触权重里**，从来没有"外部草稿纸"这个概念。

### 6.2 现有 SNN 的"记忆贫困"

| 记忆类型 | 载体 | 能"划掉重写"吗？ |
|---|---|---|
| 工作记忆 WM | 50 槽位 × 50 维签名 | 不能，只能 LRU 淘汰 |
| 海马索引 | 50K × 50 维签名 | 不能，只能 importance 衰减 |
| 突触权重 | 10.7M 突触 | 不能，PSW 是单向累积 |
| 神经元状态 | 60K 膜电位 | 能，但每步重置 |

**没有一个真正的"草稿纸"**。人脑前额叶能维持 4±1 项，但配合纸能算 100 位的乘法——**SNN 现在等于"只能口算，没有纸"**。

### 6.3 认知黑板方案

引入"认知黑板"——**位于 SNN 神经元外、但受 SNN 控制的可读写工作区**：

```
┌─────────────────────────────────────────────────────┐
│  SNN 核心网络 (60K 神经元)                           │
│  - 维持内部状态（情感/注意/意图）                    │
│  - 决策"读什么/写什么/划掉什么"                      │
└──────────────────┬──────────────────────────────────┘
                   │ 读/写/擦除 指令
                   ↓
┌─────────────────────────────────────────────────────┐
│  认知黑板 (Cognitive Blackboard)                     │
│  ┌─────┬─────┬─────┬─────┬─────┬─────┐              │
│  │ S0  │ S1  │ S2  │ S3  │ ... │ SN  │  N 个槽位   │
│  └─────┴─────┴─────┴─────┴─────┴─────┘              │
│  每个 slot:                                          │
│   - content: PCA 签名 + LLM embedding                │
│   - tag: 类型标记(FACT/CONCEPT/RELATION/GOAL/...)    │
│   - confidence: 置信度                               │
│   - emotion: 情感印记 (6 维调质快照)                 │
│   - timestamp: 写入时间                              │
│   - write_protection: 锁定/可改                      │
└──────────────────────────────────────────────────────┘
```

### 6.4 与人脑纸笔算术的对应

| 人脑算术 | SNN 对应 |
|---|---|
| 眼睛看数字 | SNN 从 LLM 输出读入 embedding → 写黑板 |
| 在纸上写数字 | SNN 通过"写头"把签名写到黑板槽位 |
| 心算中间结果 | SNN 网络演化，产生新签名 |
| 把心算结果写到纸上 | SNN 写头更新黑板槽位 |
| 划掉旧数字 | SNN 擦除头清空槽位 |
| 回头看之前的步骤 | SNN 读头读历史槽位 |
| 重新读题 | SNN 重新注入黑板内容到网络 |

### 6.5 与现有 WM 的关键区别

| 维度 | 现有 WM | 认知黑板 |
|---|---|---|
| 容量 | 50 槽 | **可配置 256-1024** |
| 操控粒度 | 整体刷新 | **逐 slot 读写擦** |
| 结构化 | 平等槽位 | **带类型标签**（FACT/CONCEPT/RELATION/GOAL/HYPOTHESIS/SCRATCH/ANCHOR） |
| 操作历史 | 无 | **有写入日志**（可回溯） |
| 内容类型 | 仅 PCA 签名 | **签名 + embedding 双模** |
| 读回机制 | 衰减注入前额叶 | **读写头受 SNN 控制** |
| 与 LLM 关系 | 无 | **可把黑板内容导出给 LLM 生成** |

### 6.6 数据结构设计

```cpp
// 新增: src/snn/cognitive_blackboard.cuh

#define BB_CAPACITY          256      // 黑板槽位数 (可扩展)
#define BB_SIGNATURE_DIM     50       // PCA 签名维度 (复用现有)
#define BB_EMBEDDING_DIM     512      // LLM embedding 维度 (bge-small-zh)
#define BB_EMOTION_DIM       6        // 情感印记维度 (6 维调质快照)

enum class SlotTag : uint8_t {
    EMPTY       = 0,   // 空槽
    FACT        = 1,   // 事实/数字 (如"用户年龄=25")
    CONCEPT     = 2,   // 概念 (如"焦虑情绪")
    RELATION    = 3,   // 关系 (如"用户→害怕→失业")
    GOAL        = 4,   // 当前目标 (如"安抚用户")
    HYPOTHESIS  = 5,   // 假设 (如"用户可能在找工作")
    SCRATCH     = 6,   // 草稿 (中间计算结果)
    ANCHOR      = 7,   // 锚点 (常驻参考点)
};

struct BlackboardSlot {
    // 内容
    float signature[BB_SIGNATURE_DIM];      // SNN 视角的"内容" (200B)
    float embedding[BB_EMBEDDING_DIM];      // LLM 视角的"内容" (2048B)

    // 元信息
    SlotTag tag;                            // 类型标签
    uint8_t confidence;                     // 置信度 (定点 /255)
    uint8_t emotion_vector[BB_EMOTION_DIM]; // 写入时情感印记 (定点)
    uint8_t write_protection;               // 0=可改, 1=锁定
    uint16_t timestamp_step;                // 写入时间步
    uint16_t last_access_step;              // 最后访问时间
    uint16_t access_count;                  // 被读次数 (热度)
};
// 容量: 256 槽 × ~592B = 151KB，显存可忽略
```

### 6.7 读写头设计（SNN 输出动作）

SNN 每步前向后输出一组"读写头信号"：

```cpp
struct ReadWriteHead {
    // 写头
    float write_attention[BB_CAPACITY];     // 写注意力分布 (softmax over slots)
    float write_signature[BB_SIGNATURE_DIM];// 要写入的签名 (从 PCA readout)
    float erase_gate;                       // 擦除门 [0,1]
    float write_gate;                       // 写入门 [0,1]
    SlotTag write_tag;                      // 要写的类型标签

    // 读头
    float read_attention[BB_CAPACITY];      // 读注意力分布
    float read_strength;                    // 读强度
};
```

**读写头如何产生**（从 SNN PCA 签名 + 一组小 readout 层）：

```
SNN PCA 签名 [50]
       ↓
    Linear [50 → 256]  + softmax  → write_attention
    Linear [50 → 50]                → write_signature
    Linear [50 → 1]   + sigmoid    → erase_gate
    Linear [50 → 1]   + sigmoid    → write_gate
    Linear [50 → 8]   + argmax     → write_tag
    Linear [50 → 256] + softmax    → read_attention
    Linear [50 → 1]   + sigmoid    → read_strength
```

**参数量**：约 50×(256+50+1+1+8+256+1) + 偏置 ≈ **30K 参数**，微不足道。

### 6.8 读写执行逻辑

```cpp
// 写操作: 对每个 slot i
for (int i = 0; i < BB_CAPACITY; ++i) {
    float w = write_attention[i] * write_gate;
    slot[i].signature = slot[i].signature * (1 - w*erase_gate) + write_signature * w;
    if (w > 0.5) {
        slot[i].tag = write_tag;
        slot[i].emotion_vector = current_neuromodulators;  // 情感印记
        slot[i].timestamp_step = current_step;
    }
}

// 读操作: 加权读回注入 SNN
float injected[50] = {0};
for (int i = 0; i < BB_CAPACITY; ++i) {
    float r = read_attention[i] * read_strength;
    for (int k = 0; k < 50; ++k)
        injected[k] += slot[i].signature[k] * r;
}
// 注入到 SNN 感官输入层 (L4)
```

### 6.9 能带来的质变

**1. 真正的"多步推理"能力**

现在 SNN 只能"口算"——每步前向，状态靠神经元维持。有了黑板：

```
步骤1: LLM 说"用户25岁" → SNN 写 slot[0] = {25岁, FACT}
步骤2: SNN 读 slot[0] → 内部推理 → 写 slot[1] = {青年, CONCEPT}
步骤3: LLM 说"用户在求职" → SNN 写 slot[2] = {求职, FACT}
步骤4: SNN 读 slot[0,1,2] → 推理 → 写 slot[3] = {可能缺钱, HYPOTHESIS}
步骤5: SNN 读 slot[3] → 决策回复语气
```

**5 步推理链**，每步都有外部记忆支撑——这在纯 SNN 神经元动力学里是不可能的。

**2. 可解释性**

黑板内容可直接可视化：GUI 显示每个 slot 的 tag + confidence + emotion，用户能看到 SNN"在想什么"。**这是 GUI 产品的杀手锏**。

**3. 与 LLM 的双向桥接**

```
LLM embedding (512 维) ←→ 黑板 embedding (512 维)
SNN 签名 (50 维)      ←→ 黑板 signature (50 维)
```

- LLM 把"用户说 X"→ embedding → 写黑板
- SNN 读黑板 → 推理 → 写新签名
- 导出黑板 slot → LLM prompt 拼接 → 生成回复

**4. 情感印记的载体**

每个 slot 写入时记下当时的 6 维调质状态——**这就是"情感记忆印记"的物理载体**。回忆时不仅匹配内容，还匹配情感状态。

### 6.10 与现有系统的集成

| 现有模块 | 在黑板方案中的角色 |
|---|---|
| PCA 压缩层 | 提供 SNN → 黑板的签名 |
| 调质系统 | 给写入打情感印记 |
| 前额叶神经元 | 接收黑板读回的注入 |
| 海马索引 | 黑板满时溢出到海马（短期→长期） |
| 睡眠重放 | 把黑板的 HYPOTHESIS/GOAL 固化到突触 |
| 丘脑门控 | 控制读注意力强度 |

### 6.11 风险与诚实评估

| 风险 | 说明 |
|---|---|
| **读写头训练问题** | 30K 参数的 readout 好定义，但"该写哪个 slot、写什么内容"需要训练信号。可用监督训练（标注"在这种对话状态下应记什么"），数据成本不低 |
| **注意力 collapse** | softmax 写注意力可能塌缩到少数 slot。需要 entropy 正则 |
| **黑板的"内容"仍是 PCA 签名** | 不是自然语言。要把签名翻译回语言必须经 LLM。**黑板是 SNN 的草稿纸，不是用户的草稿纸** |
| **不要把黑板当成 RAG** | 黑板是 SNN 的工作区，不是知识库。知识库仍是 LLM+RAG |

## 7. 方向三：工具编排（Tool Orchestration）

### 7.1 核心洞察

> **人脑不是通用计算器，而是通用调度器。**
> 人脑的强大不在于"会算"，而在于"会用工具算"。
> SNN 现在的问题恰恰是——被强迫成为计算器，而不是调度器。

原方案让 SNN 做 6 分类头 = 强迫它"算"。情感核心让它"维持状态"。认知黑板让它"记草稿"。
**工具调用让它"用工具"——这才补全了认知架构的最后一环。**

人脑做事的方式：

| 人脑做的事 | 人脑不做的事 |
|---|---|
| 决定"什么时候算" | 精确执行大数乘法 |
| 决定"算什么" | 维护 100 位数字 |
| 决定"用什么工具" | 自己变成计算器 |
| 调度工具、解读结果 | 替代工具 |

### 7.2 三个方向的递进关系

不是替代，是递进叠加，构成完整的**前额叶执行控制系统**：

```
┌─────────────────────────────────────────────┐
│  Layer 3: 工具编排 (Tool Orchestration)      │  ← 本章
│  SNN 调度外部能力                             │
├─────────────────────────────────────────────┤
│  Layer 2: 认知工作空间 (Blackboard)          │  ← 第 6 章
│  SNN 操控外部记忆                             │
├─────────────────────────────────────────────┤
│  Layer 1: 情感核心 (Affective Core)          │  ← 第 3 章
│  SNN 维持内部状态                             │
└─────────────────────────────────────────────┘
```

三者构成完整的执行控制：
- 内部状态（情感核心）→ 决定"想做什么"
- 外部记忆（黑板）→ 决定"记得什么"
- 外部能力（工具）→ 决定"用什么做"

### 7.3 工具集设计

**核心工具集（6 个）**：

| 工具 | 输入 | 输出 | 对应人脑/认知 |
|---|---|---|---|
| **Transformer 生成器** | prompt + 调质状态 | 文本 | 语言区（Broca/Wernicke） |
| **计算器** | 算式 | 数值结果 | 外部符号操作（纸笔算术） |
| **草稿记录器** | 内容 + 标签 | 写入确认 | 工作记忆外化（笔记本） |
| **长程检索器** | 查询签名 | 检索结果 | 海马回忆 |
| **知识库查询** | 关键词 | 文档片段 | 事实回忆（RAG） |
| **时钟** | 无 | 当前时间 | 昼夜节律感知 |

### 7.4 SNN 如何调用工具

**关键设计**：SNN 输出一组"工具调用信号"，不是离散分类，而是**连续的工具注意力 + 参数调制**：

```cpp
struct ToolCallSignal {
    // 工具选择（连续注意力，非 argmax）
    float tool_attention[N_TOOLS];        // 6 个工具的注意力分布

    // 调用强度（0=不调用, 1=强调用）
    float call_strength;

    // 工具参数调制（SNN 内部状态注入工具）
    float neuromodulator_injection[6];    // 把当前情感状态传给工具
    float signature_injection[50];        // 把当前 PCA 签名传给工具

    // 草稿槽位指针（与黑板联动）
    int   scratch_slot_idx;               // 工具结果写到黑板哪个槽
};
```

**为什么不做成 argmax 分类**：
- argmax = 每轮选一个工具 → 退化回分类器
- 连续注意力 = 可以**同时调用多个工具**（如：检索 + 计算 + 记录并行）
- `call_strength` 可以是 0 → **可以选择不调用任何工具**（纯内部推理）

### 7.5 关键：如何避免退化成分类器

这是最大的陷阱。如果实现成"每轮 SNN 输出 `tool_id ∈ {0,1,2,3,4,5}`"，就又回到了我们批评的 6 分类头方案。

**解决方案：工具调用受状态演化驱动**

工具调用决策必须**来自 SNN 内部状态的连续演化**，而不是独立的分类头：

```
用户输入
   ↓
[SNN 状态演化 T 步]
   - 膜电位动态
   - 调质浓度变化
   - PCA 签名生成
   ↓
[从状态 readout 工具调用信号]
   - tool_attention = softmax(Linear(pca_sig))
   - call_strength = sigmoid(Linear(pca_sig))
   - 但工具调用是否触发, 还要看:
     * 调质门控 (DA 高时倾向调用生成器)
     * 丘脑门控 (注意力聚焦时才调用)
     * 黑板状态 (有未解决槽位时才调用)
   ↓
[工具执行 (可能不触发)]
   ↓
[结果写回黑板]
   ↓
[SNN 继续演化]
```

**关键区别**：
- 分类器：`tool_id = argmax(MLP(features))` —— 每轮独立决策
- 状态驱动：`tool_call = f(state_trajectory, modulator_levels, blackboard_state)` —— 决策来自状态历史

### 7.6 状态驱动的具体表现

- 用户连续问 3 次计算题 → SNN 的"计算模式"突触被 STDP 强化 → 第 4 次更快触发计算器（**习惯形成**）
- 用户情绪激动 → DA/NE 上升 → 工具调用阈值降低，更倾向调用生成器快速回应（**情绪驱动决策**）
- 黑板上有未解决的 HYPOTHESIS 槽位 → SNN 倾向调用检索器验证（**目标驱动行为**）

这些是**纯分类器做不到的**——它们依赖时序状态累积。

### 7.7 训练方案

给 SNN 学会"什么时候用什么工具"的训练信号从哪来？

#### 方案 A：监督训练（简单但天花板低）

标注数据：`(对话状态, 应调用工具)` 对。
- 优点：简单
- 缺点：标注成本高，且学不到"基于状态演化"的决策

#### 方案 B：强化学习（推荐）

SNN 作为 agent，工具调用作为 action，对话质量作为 reward：

```
state  = (SNN 内部状态, 黑板内容, 对话历史)
action = (tool_attention, call_strength, scratch_slot_idx)
reward = 用户反馈 (点赞/纠正) + 启发式 (回复相关性)
```

- DA 价值函数**已实现**（[config.h L364](../src/snn/config.h)），可直接用作 reward 信号
- TD error 驱动 STDP 更新 → SNN 学会"在状态 X 下调用工具 Y 能获得更高 reward"

**这正好用上了现有的 DA 价值函数**——之前它服务于字节预测，现在服务于工具调用决策，更有意义。

#### 方案 C：模仿学习（折中）

用 LLM（如 GPT-4）作为"教师"，在相同对话状态下决定该用什么工具，SNN 模仿其决策。
- 优点：数据生成自动化
- 缺点：LLM 教师不基于时序状态，可能学不到 SNN 特有的决策模式

**推荐**：方案 B 为主 + 方案 C 冷启动。

### 7.8 训练时的工具集成

工具必须**端到端训练工具调用策略**，不能训练完再接工具。

**训练循环设计**：

```
for each training episode:
    1. 重置 SNN 状态 + 黑板
    2. for turn in dialog_episode:
        a. 用户输入 → SNN 演化 T 步
        b. SNN 输出 tool_call_signal
        c. 工具执行 (可能是 no-op)
        d. 工具结果写回黑板
        e. SNN 读黑板 → 继续演化
        f. 最终输出 (经 Transformer 生成器)
        g. 用户反馈 → DA reward
        h. STDP 更新 (基于 DA + eligibility trace)
    3. 睡眠重放: 巩固工具调用策略
```

**关键：工具调用是可微的吗？**

不是。工具调用是离散动作（调用了/没调用、调用了哪个）。所以**不能用 BPTT**，必须用：
- 策略梯度（REINFORCE）—— SNN 输出工具选择概率，reward 加权更新
- 或 PSW 贝叶斯更新（现有机制）—— 把工具调用成功/失败作为 LTP/LTD 证据

**现有 PSW 机制完美适配**：工具调用成功 → α 累积（强化该决策路径）；调用失败 → β 累积（削弱）。不需要新训练算法。

### 7.9 与现有架构的集成

| 现有模块 | 工具编排中的角色 |
|---|---|
| DA 价值函数 | **工具调用的 reward 信号**（核心复用） |
| PSW 贝叶斯突触 | **工具调用策略的学习机制**（核心复用） |
| 调质系统 | 调制工具选择倾向（DA 高→探索新工具） |
| 丘脑门控 | 控制工具调用阈值（注意力高时才调用） |
| 海马索引 | 记忆"上次在类似状态下用了什么工具" |
| 工作记忆 | 暂存工具结果 |
| 黑板（新增） | 工具结果的写入目标 |

**几乎所有现有机制都能派上用场**。

### 7.10 风险与诚实评估

| 风险 | 说明 | 缓解 |
|---|---|---|
| **训练复杂度爆炸** | 端到端训练工具调用策略 = RL + SNN + 多工具环境，比纯监督训练难一个量级 | 先用方案 C（模仿学习）冷启动，再切换到方案 B（RL）微调 |
| **工具调用可能不触发** | SNN 可能学会"什么都不调用最安全"（reward 平稳） | 好奇心驱动探索（预测误差大时强制尝试工具）+ DA 探索奖励 |
| **与 LLM 工具调用重复** | LLM 本身也有 tool calling 能力，SNN 做工具路由是否多余？ | 关键区别：LLM 工具调用基于当前 prompt 的独立决策，无时序状态；SNN 基于跨轮次状态演化的决策，有习惯/情绪/目标驱动。但这个优势需要训练才能体现，PoC 阶段可能不明显 |
| **工具粒度问题** | "计算器"是一个工具还是多个？"生成器"是一个工具还是按任务分？ | 粗粒度开始（5-6 个工具），后续按需细化 |

### 7.12 工具编排的深层意义

你的洞察把 SNN 的定位从"记忆系统"推进到"**认知调度系统**"——这才是前额叶的真正职责。

**三层架构的完整性**：
- 情感核心：SNN 维持**内部状态**
- 认知工作空间：SNN 操控**外部记忆**
- 工具编排：SNN 调度**外部能力**

三者缺一不可。只有情感核心，SNN 只是"情绪计"；加黑板，SNN 是"会记草稿的情绪计"；加工具编排，SNN 才是完整的"**认知调度器**"。

**最关键的设计原则**：工具调用必须**受 SNN 内部状态演化驱动**，不能是独立的分类头。否则就又回到了我们批评的"6 分类头"陷阱。

**最让人兴奋的点**：现有的 DA 价值函数 + PSW 贝叶斯突触 + 丘脑门控，几乎是为工具调用 RL 训练"预制"的——reward 信号、学习机制、注意力控制全部就位。

## 8. 结论：情感核心 + 认知工作空间 + 工具编排 应作为 Phase 3 真正方向

### 8.1 三个方向的关系

三个方向**不是三选一，而是同一个方案的递进叠加**，构成完整的"前额叶执行控制系统"：

| 方向 | 解决的问题 | 时间尺度 | 对应认知功能 |
|---|---|---|---|
| 情感核心 | SNN 维持什么内部状态 | 跨轮次的情感演化 | 边缘系统 / 杏仁核 |
| 认知工作空间 | SNN 如何扩展工作记忆 | 单轮内的多步推理 | 前额叶工作记忆 |
| 工具编排 | SNN 如何调度外部能力 | 按需触发的外部调用 | 前额叶执行控制 |

**天然耦合点**：
- 情感状态写入黑板（黑板 slot 带 emotion_vector）
- 黑板每个 slot 带情感印记（写入时调质快照）
- 短期情感记忆进黑板，长期情感记忆进海马
- 工具结果写回黑板（黑板是工具与 SNN 的交汇点）
- 情感状态调制工具选择（DA 高→探索新工具，5HT 高→保守稳重）
- 工具调用 reward 经 DA 价值函数反馈给 SNN（学习闭环）
- 黑板是 GUI 可视化的核心（显示每个 slot 的 tag + emotion + confidence + 来源工具）

### 8.2 为什么这个组合优于原方案

| 维度 | 原 Phase 3（6 分类头） | 情感核心 + 黑板 + 工具编排 |
|---|---|---|
| SNN 不可替代性 | 弱（MLP 可替代） | 强（时序状态 + 外部工作区 + 工具调度） |
| 现有 31 种生物机制复用率 | ~10%（只用 PCA readout） | ~85%（调质 + 海马 + WM + STDP + 门控 + DA 价值函数全用上） |
| 可解释性 | 低（6 个标签） | 高（黑板可视化 + 情感轨迹 + 工具调用日志） |
| GUI 卖点 | 弱 | 强（黑板卡片 + 情感曲线 + 记忆热度 + 工具调用流） |
| 多步推理 | 不支持 | 支持（黑板读写头 + 工具链式调用） |
| 个性化 | 仅靠 prompt 模板 | STDP 印记 + 情感记忆 + 用户隔离 + 工具使用习惯 |
| 延迟 | 三阶段 + 重生成 > 4 秒 | 前置调制 + 单次生成 + 按需工具 < 2 秒 |
| 训练范式 | 监督分类（需要 50K 标注） | RL + 模仿学习（DA reward 驱动，复用现有价值函数） |

### 8.3 实施路径建议

```
Phase 3a: 情感核心 (SNN 调质系统 + 6 维 readout + LLM 调制接口)        [2-3 周]
Phase 3b: 认知黑板 (256 槽 + 读写头 + 基础读写操作)                    [3-4 周]
Phase 3c: 黑板-LLM 桥接 (embedding 双向 + 导出 prompt)                 [2 周]
Phase 3d: 工具编排核心 (6 工具 + 状态驱动调用信号 + 黑板联动)          [3-4 周]
Phase 3e: 工具调用训练 (模仿学习冷启动 + RL 微调 + DA reward 闭环)     [3-4 周]
Phase 3f: 黑板-海马溢出 (短期→长期固化 + 情感印记)                     [2 周]
Phase 3g: 端到端验证 (情感轨迹可视化 + 多步推理 + 工具调用 demo)       [2 周]
```

### 8.4 一句话总结

> **人脑的强大不在于神经元多，而在于会用工件（纸、笔、手指、语言、工具）扩展工作记忆与能力**。
>
> - 情感核心让 SNN 找到真正不可替代的角色——维持跨轮次的连续情感状态，
>   调制 LLM 的生成过程本身，而非给它贴标签。
> - 认知黑板让 SNN 从"只能口算"升级到"会打草稿"——这是工作记忆的扩展。
> - 工具编排让 SNN 从"被迫当计算器"升级到"调度外部能力"——这是执行控制的完整形态。
>
> **情感核心 + 认知黑板 + 工具编排 = SNN 从"被保留的累赘"变成"完整的前额叶认知调度器"**。

## 附录 A：人类情感神经调质参考

### 核心神经调质（6-8 种，工程建模目标）

| # | 名称 | 主要来源 | 情感作用 | 工程参数建议 |
|---|---|---|---|---|
| 1 | 多巴胺 (DA) | VTA / 黑质 | 奖励、动机、愉悦、期待 | reward signal, 探索驱动 |
| 2 | 血清素 (5-HT) | 中缝核 | 情绪稳定、满足、抑制冲动 | temperature ↓, 稳态调节 |
| 3 | 去甲肾上腺素 (NE) | 蓝斑 | 警觉、唤醒、应激、聚焦 | arousal ↑, top_p ↓ |
| 4 | 乙酰胆碱 (ACh) | 基底前脑 | 注意力、学习、记忆编码 | attention gain, 检索强度 |
| 5 | GABA | 全脑抑制中间神经元 | 抑制、平静、抗焦虑 | 抑制性调制，降温 |
| 6 | 谷氨酸 | 全脑兴奋主递质 | 兴奋总量、激活水平 | 兴奋性基底 |
| 7 | 催产素 | 下丘脑 | 信任、亲密、共情、社交联结 | 共情强度, social_mode |
| 8 | 内啡肽 | 下丘脑-垂体 | 镇痛、愉悦、减压 | 满足感, 缓解信号 |

### 次要 / 新兴情感调质（扩展用）

组胺、褪黑素、P物质、食欲素、甘丙肽、NO（一氧化氮）

### 激素（内分泌，慢背景，不建议建模）

皮质醇、肾上腺素、睾酮、雌激素/孕酮、甲状腺素、催乳素、CRH

### 情感理论的"最小完备集"

- **核心神经调质**：6-8 种
- **加激素背景**：再 +3-4 种
- **总计**：10-12 种基本覆盖人类情感谱

注意：**不是 1 种调质 = 1 种情绪**。情感是调质的**组合模式**：
- "愉悦" ≈ DA↑ + 内啡肽↑ + NE 中等 + 5-HT 中等
- "焦虑" ≈ NE↑↑ + 5-HT↓ + 皮质醇↑ + GABA↓
- "爱" ≈ 催产素↑ + DA↑ + 5-HT 波动 + 内啡肽↑

| 候选方向 | 用到的领地 | 卖点 | 难度 | 综合评分 |

| **工具编排** | 1+2+3 | 认知调度器、复用 DA 价值函数做 RL | 中高 | ★★★★★ |
| **用户人格印记** | 2 | 几次交互形成不可迁移的个性 | 中 | ★★★★ |
| **对话张力/节奏控制器** | 1+3 | 控制 LLM 何时主动追问 | 中 | ★★★ |
| **预测编码式好奇心** | 1+2 | SNN 预测用户下一句，预测错就主动探索 | 高 | ★★★ |
