# PSW 证据指标分析与诊断记录

> 记录时间: 2026-08-01 23:50 (Asia/Shanghai)
> 场景: 具身沙盒 V1（hunger_feeding）N3F 训练，20K 长程验证
> 关联文档: [N3F训练进度_2026-08-01.md](./N3F训练进度_2026-08-01.md)

## 1. 问题背景

20K 沙盒验证完成（exit code 0），主要指标全部正常（PCA W_norm 稳定 15-20、
阶段切换正确、结构可塑性工作、解码 ppl 5.4、行为 hunger→cry 循环成立），
但 **criterion_psw = 0**：

| 指标 | v6 3000步(全 EMBRYONIC) | v6 20K(5K 胚胎+15K 突触期) |
|---|---|---|
| psw_mean_alpha | 0.0167 | 0.0076 |
| psw_mean_beta | 0.0690 | 0.0283 |
| psw_mean_evidence (α+β) | 0.0857 | **0.0358** |
| psw_mature_ratio | 0 | 0 |

关键数值吻合：`0.0358 ≈ 0.1 × 0.95^20`（纯衰减曲线，每 1000 步 ×0.95）。

## 2. 排查过程

### 2.1 初步怀疑：SYNAPTOGENIC 后证据不累积

进入 SYNAPTOGENIC（5K+，plast_gain=1.0）后，PSW 证据更新被
`plasticity_gain` 门控（[synapse_kernels.cu](../src/snn/synapse_kernels.cu#L275-L291)）：
`evidence = eta × effective_signal × plasticity_gain × M_ij × plasticity_factor`，
gain 应使证据开始累积。但实测 20K 结束后证据仍在纯衰减。

### 2.3 诊断结论

| step | evidence | 相邻比值 | 阶段 |
|---|---|---|---|
| 4000 | 0.07738 | — | EMBRYONIC (gain=0) |
| 5000 | 0.07351 | 0.9500 | 阶段切换点 |
| 6000 | 0.06983 | 0.9500 | **SYNAPTOGENIC (gain=1.0)** |
| 7000 | 0.06634 | 0.9500 | 同上 |

- **证据链路两个信号源都活着**：`elig_nz=60000`（全神经元非零，均值 -0.07~-0.21），
  `e1_nz=28-39%`（突触级 e1 trace 非零，均值约 -1.5e-4）。
- **但 5K 后 gain=1.0，evidence 依然精确 ×0.95/1000 步** —— 增量严格为 0，
  不是"增量 < 衰减"，是"增量 = 0"。

### 2.4 增益对照实验（无效）

将 `ELIGIBILITY_EVIDENCE_GAIN` 0.1 → 1.0（×10）后重跑 8K：
5K 后 evidence 仍精确 ×0.95 纯衰减（0.07351→0.06983→0.06634，与修复前逐位相同）。
**增益不是原因，链路断在更根本处。**

证据更新路径（[synapse_kernels.cu](../src/snn/synapse_kernels.cu#L268-L281)）：
```
effective_signal = ELIGIBILITY_EVIDENCE_GAIN × e1[i] × neuron_eligibility[post]
evidence = eta(200) × effective_signal × plasticity_gain × M_ij × plasticity_factor
→ synapse_alpha/beta += evidence
```
理论估算单事件 evidence ≈ 2e-4（增益 0.1 时），每 1000 步增量 ≈ 2.4e-3，
本应大于衰减 3.7e-3 —— 但实测精确为 0，说明 effective_signal 计算路径实际未产出增量。

### 2.5 结构衰减机制（设计意图）

[scheduler.cu](../src/snn/scheduler.cu#L1206-L1218) `launch_structural_plasticity`：
- 每 1000 步调用 `structural_plasticity_decay_kernel`
- `decay_factor = 0.95f`，`evidence_threshold = phase.prune_threshold`
- SYNAPTOGENIC 阶段 `prune_threshold = 0` → **弱突触重置分支永不触发**
  （`α+β < 0` 不可能），证据只衰减、无重置兜底
- 注释明确：衰减 = "遗忘"机制，让已学习突触重新可塑（有意设计）

## 3. 认知修正（核心结论）

### 3.1 PSW 指标的意义

PSW（Probabilistic Synaptic Weights）是**突触局部的贝叶斯置信度表示**，不是全局学习目标：
- `α/(α+β)` = 权重方向（LTP/LTD 证据比例）
- `α+β` = 证据总量（置信度）
- 成熟（α+β > 0.2）= **单个突触**被巩固 —— 是"部分突触选择性巩固"，
  不是"全局证据必须达标"

### 3.2 之前的两个错误认知

1. **把"20K 内 PSW 成熟"当验证目标** —— 错误。SYNAPTOGENIC 是 5K-200K
   （195K 步窗口），20K 只过了 15K 步可塑性。成熟是长尺度下"持续被强化的突触
   在遗忘中存活并巩固"的结果，不该是 15K 步的目标。
2. **证据衰减被当作 bug** —— 错误。衰减是明确的"遗忘"设计。且全局均值被
   72% 不活跃突触稀释，`mean_evidence ≥ 0.09` 的 criterion 判据本身粗糙
   （[main.cpp](../src/snn/main.cpp) `criterion_psw`），正确判据应为
   `mature_ratio > 0`（是否有部分突触在巩固）或考察活跃突触子集。

### 3.3 真正需要关注的疑点

**增量严格为 0 意味着 N3F 具身学习信号（effective_signal = gain·e1·elig）
没有到达突触**。这影响的不只是 criterion_psw，而是整个具身学习是否真的在
修改突触（w_eff 由 α/β 决定）。这是需要进一步定位的问题，但不是
"为了让 PSW 达标"——**"成熟"不是 20K 目标**。
